== A Minecraft server that sleeps until someone wants to play

A stock HorizontalPodAutoscaler never goes below one replica, and a workload at zero replicas
cannot report its own demand. This workshop solves both problems with the OpenShift Custom
Metrics Autoscaler (CMA): a small always-on proxy, `mc-waker`, answers players while the server
sleeps and publishes a 0/1 "please wake up" metric; CMA reads it and scales the Minecraft
Deployment from zero to one and back. The facilitator runs every step; the audience joins the
server at the end.
